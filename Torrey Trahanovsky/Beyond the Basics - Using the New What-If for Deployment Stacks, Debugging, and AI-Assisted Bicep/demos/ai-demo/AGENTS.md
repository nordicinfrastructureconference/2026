# Demo workspace rules

This folder is used for a live conference demo.

- Use only the two skills in `.github/skills`: `migrate-resources-to-stack` and `convert-template-to-stack`. Don't load any other skill.
- Only read and write files inside this folder. Don't open files anywhere else on the machine.
- Never create, update, or delete a deployment stack. Stop at the Stacks What-If and hand back.
