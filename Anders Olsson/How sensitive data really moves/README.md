How Sensitive Data Really Moves (AI-Driven Investigations with DSPM, DSI and Security Copilot)

Speaker: Anders Olsson

Summary
Sensitive data no longer stays in one place. It moves across Microsoft 365, endpoints, cloud services, and AI tools faster than organizations can track, often creating exposure without visibility or control.

In this session, Anders shares insights from 15 years of real-world data security projects and demonstrates how Microsoft Purview DSPM, Microsoft Security Copilot, and Data Security Investigations (DSI) can be used together to uncover how sensitive data actually moves inside your environment.

Through live scenarios, you will see how to:

Discover where sensitive data exists across Microsoft 365
Identify oversharing and unintended exposure
Investigate real incidents using DSI and Security Copilot
Correlate signals across Defender XDR, DLP, and Insider Risk
Turn complex telemetry into actionable investigation insights using AI
Welcome to a demo-driven session focused on real-world challenges, showing how modern AI-assisted investigations can give you visibility into risks you likely don’t see today.
